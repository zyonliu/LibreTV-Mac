安装说明

请先退出正在运行的 LibreTV，再安装到“应用程序”文件夹。安装过程不添加后台守护程序，也不修改系统网络或安全设置。

影片、缓存、数据源和观看历史保留在当前用户目录中，不随安装包替换。关闭主窗口会退出软件并回收其本地服务和测活任务。

这是未公证的 Local 包，不具备正式 Developer ID 分发信任。macOS 的 Gatekeeper 可能阻止打开；正式分发需要 Developer ID Application、Installer 签名和 Apple 公证。

完整源码和构建说明见 https://github.com/zyonliu/LibreTV-Mac，桌面版本标签 v1.0.0。LibreTV 采用 AGPL-3.0-or-later 许可；应用内附官方与 Node.js 许可文件。
