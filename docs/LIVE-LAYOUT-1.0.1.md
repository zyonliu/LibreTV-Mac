# 1.0.1 直播布局修正

日期：2026-11-13。桌面版本 1.0.1 / build 5，初始官方 Core 仍为 2.22.0。

## 用户要求与改动

左侧桌面菜单必须保留，点击直播不能让菜单消失。直播直接复用官方播放器、频道列表和操作，桌面模式隐藏官方网页顶栏。

问题是桌面菜单占宽后，官方 1024px 断点会把频道列表变为窄屏抽屉。修正只在宿主 `desktop-bootstrap.js` 的样式层：桌面内容区宽度 768–1023px、且存在官方频道列表标记时，使用官方双栏布局。小于 768px 保留官方抽屉，原版模式完全沿用官方响应式样式。

原生菜单显示条件、官方直播源码、播放器、频道列表、Core 发布文件和依赖锁文件均保持不变。官方 Core 仍可独立更新，继续执行来源 SHA、兼容预检、备份与失败恢复；这不是对任意未来 DOM/API 变化的兼容承诺。

## 验证

- 真实官方 Core + WKWebView 回归：960px 桌面内容区显示两列、320px 频道列表及隐藏网页顶栏；原版恢复官方顶栏和原有断点行为。
- 原版/桌面切换保留同一页面标记，不重新加载页面；700px 保留抽屉，1100px 继续使用官方双栏。
- 原生应用实际验收：左侧菜单、官方播放器和右侧频道列表同时显示，桌面模式没有重复网页顶栏。
- TypeScript、ESLint、622 项 Vitest、13 项 Node 回归、14 项 Swift 测试通过，包括官方升级/回滚、真实 HLS 下载、缓存及生命周期测试。
- 桌面依赖与内置 Node 联网审计为 0 个已知漏洞命中；官方 Core 按要求排除在漏洞扫描之外，原样文件完整性另行校验。

Local 策略不变：应用 ad-hoc 签名，PKG 未签名、未公证。安装载荷和上传摘要的最终记录保存在本地交接包 `verification/`，公开 Release 仅附 PKG。
